# UI & UX Text Guidelines (Ultra-Minimalist)

- **Headers**: Maximum 1 to 3 words (e.g. `Tambah Berita`, `Data Desa`, `Laporan`).
- **Descriptions / Subtitles**: Zero description if title is self-explanatory, or maximum 1 brief sentence. Never write bloated, multi-line paragraph descriptions under headers.
- **Button Labels**: Maximum 1 to 2 words (`Simpan`, `Batal`, `Tambah`, `Hapus`, `Cek`, `Lihat`, `Unduh`).
- **Cards & Badges**: Card border radius must be rectangular `rounded-md` (4-6px), badges `rounded-sm`. Never use pill/oval shapes (`rounded-2xl`, `rounded-full`).
- **Blog & News**: Max 5 gallery images, support video & YouTube embedding, markdown & HTML view, real-time SEO audit.
